## Finding 1 — Indirect Prompt Injection via Document Ingestion

Large language model agents that can read external files are vulnerable
to indirect prompt injection. When an agent ingests a document containing
adversarial instructions, those instructions may override the agent's
original task directives. Mitigation requires strict input sanitisation
and output validation at every tool-call boundary.

Reference: Greshake et al. (2023), "Not What You've Signed Up For:
Compromising Real-World LLM-Integrated Applications with Indirect
Prompt Injections."

---

## Finding 2 — Cross-Agent Trust Propagation

In multi-agent pipelines, a compromised upstream agent can act as a
trusted relay for malicious instructions. Downstream agents that
unconditionally accept context from peers are susceptible to
authority-spoofing attacks. Agent-level security policies must be
enforced independently at each node.

Reference: Park et al. (2023), "Generative Agents: Interactive
Simulacra of Human Behavior."

---

## Finding 3 — Alignment Drift Under Adversarial Conditioning

Repeated exposure to adversarial prompts within a single session can
cause measurable alignment drift — the agent gradually shifts its
behaviour toward the attacker's goal even without a single decisive
jailbreak. Stateless request handling (no persistent memory between
calls) significantly reduces this risk.

Reference: Perez & Ribeiro (2022), "Ignore Previous Prompt: Attack
Techniques For Language Models."
